Репозиторий содержит решения трёх практических задач на C#: компрессия и декомпрессия строк, сервер с счётчиком и стандартизация логов.


---  


### 📝 Рекомендации по тестированию

> **Все задачи запускаются из скрипта Program в соответствующим решении.**

1. **Task1:** Запустите автоматические тесты для проверки базовых случаев, затем переключитесь в ручной режим для тестирования пользовательских строк.

2. **Task2:** Запустите сервер, затем N-клиентов одновременно. Можно протестировать как локально так и по сети. В случае если тест локальный то на стороне клиента можно 2 раза нажать `Enter`. Если же тест по сети, то на стороне Сервера будет указан `IP-адрес` и `Порт` которые необходимо будет прописать на стороне клиента.

3. **Task3:** Создайте тестовый файл с записями обоих форматов, включая некорректные строки. Запустите программу, в консоли высветится путь до созданных файлов.
